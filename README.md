# سامانه جامع کارشناسان رسمی دادگستری (تعرفه ۱۴۰۵) — نسخه PWA

این پوشه یک اپلیکیشن وب پیشرونده (PWA) کامل است که روی گیت‌هاب پیجز قابل انتشار است و
کاربران می‌توانند آن را روی اندروید و آیفون مثل یک اپ واقعی نصب کنند.

## فایل‌ها
```
index.html                  فایل اصلی برنامه
manifest.json                مشخصات نصب (نام، آیکون، رنگ تم)
sw.js                        Service Worker برای کارکرد آفلاین
icons/icon-192.png           آیکون ۱۹۲×۱۹۲
icons/icon-512.png           آیکون ۵۱۲×۵۱۲
icons/icon-512-maskable.png  آیکون maskable برای اندروید
icons/apple-touch-icon.png   آیکون مخصوص آیفون (۱۸۰×۱۸۰)
```

## مراحل انتشار روی GitHub Pages

1. یک ریپازیتوری جدید در گیت‌هاب بسازید (مثلاً `karshenasan-tarefe`).
2. تمام فایل‌های این پوشه (`index.html`, `manifest.json`, `sw.js`, پوشه `icons`) را
   دقیقاً با همین ساختار و اسم، در ریشه (root) ریپازیتوری آپلود کنید — نباید داخل
   زیرپوشه دیگری باشند، و اسم فایل‌ها/مسیرها را تغییر ندهید چون کد داخلی به همین
   مسیرهای نسبی اشاره می‌کند.
3. به تنظیمات ریپازیتوری بروید: **Settings → Pages**
4. در بخش **Build and deployment**، گزینه **Source** را روی **Deploy from a branch**
   بگذارید و شاخه (branch) `main` و پوشه `/ (root)` را انتخاب کنید، سپس **Save** بزنید.
5. بعد از چند دقیقه، آدرسی شبیه این فعال می‌شود:
   `https://<username>.github.io/<repo-name>/`
6. همین آدرس را در مرورگر گوشی (Chrome در اندروید یا Safari در آیفون) باز کنید.

**مهم:** گیت‌هاب پیجز به‌صورت خودکار HTTPS می‌دهد؛ Service Worker (که قابلیت نصب و
کارکرد آفلاین را فراهم می‌کند) فقط روی HTTPS کار می‌کند، پس نیازی به تنظیم اضافه نیست.

## نصب توسط کاربر

- **اندروید (Chrome):** بعد از باز شدن صفحه، یک نوار بالای صفحه با دکمه «نصب» ظاهر
  می‌شود؛ با زدن آن، پنجره نصب استاندارد کروم باز می‌شود. اگر بسته شود، همان دکمه
  نصب در نوار بالای برنامه (کنار دکمه راهنما) همیشه در دسترس است.
- **آیفون (Safari):** چون اپل اجازه نصب خودکار نمی‌دهد، با زدن دکمه «نصب»، راهنمای
  گام‌به‌گام (دکمه Share ← Add to Home Screen) به کاربر نمایش داده می‌شود.

## نکته درباره به‌روزرسانی

اگر بعداً محتوای `index.html` را تغییر دادید، نام `CACHE_NAME` در فایل `sw.js` را
هم عوض کنید (مثلاً `v1` به `v2`) تا مرورگر کاربرانی که قبلاً نصب کرده‌اند، نسخه
جدید را دریافت کنند.
